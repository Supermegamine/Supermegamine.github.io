# Portfolio

Built with [Astro](https://astro.build), deployed to GitHub Pages via GitHub Actions.

## Local development
```bash
npm install
npm run dev      # http://localhost:4321
```

## Edit your content
Everything lives in `src/data/profile.ts`. Replace each `TODO`.
Also set your username in `astro.config.mjs`.

## Deploy
1. Create a GitHub repo named `YOUR-GITHUB-USERNAME.github.io` and push this project to `main`.
2. In the repo: **Settings → Pages → Source: GitHub Actions**.
3. Every push to `main` now rebuilds and publishes the site.
